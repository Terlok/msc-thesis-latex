# Master's Thesis: Time Series Visualization

LaTeX source code for the master's dissertation: **"Time Series Visualization and Analysis Subsystem for Web-Based Robotic Systems"**.

## 📝 Abstract

This research focuses on adapting SCADA time-series telemetry concepts to robotic systems analysis. It explores the design, development, and implementation of a web-oriented subsystem for visualizing, processing, and analyzing telemetry data generated by robotic platforms.
